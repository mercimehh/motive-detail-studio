# MOTIVE Detail Studio

Портфолио-концепт сайта вымышленной детейлинг-студии. Форма работает только как локальная демонстрация и никуда не отправляет данные.

## Локальный запуск

```bash
npm ci
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```

## Изображения

Источник и лицензионный статус демонстрационных изображений не подтверждены. Перед публичным коммерческим использованием необходимо проверить их происхождение и права на использование.
